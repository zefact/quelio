WHY QUELIO

「欲しかったのに、なかった」から作った

Quelioは、既存のDBクライアントでは満たせなかった開発現場の3つの困りごとを解決するために生まれました。 この3つが、Quelioのいちばんの機能です。

01

環境のスキーマ差異が見えない

「ステージングでは動くのに本番で落ちる」。原因はたいてい、環境間のわずかなスキーマのずれ。Quelioは2つの環境を並べて、テーブル・カラム・インデックスの差異を一発で洗い出します。

スキーマ比較を見る ↓
02

作業のエビデンスが手間

調査や本番作業のたびに、クエリと結果をスクショして報告資料に貼る。その手作業をなくすため、実行と同時にクエリ+結果をきれいなPNGとして自動保存します。

自動キャプチャを見る ↓
03

カラムの意味が分からない

「この英語カラム、何だっけ」。DBコメントに書いた日本語の論理名や説明を、構造ビューの専用カラムとして表示。テーブル定義書を開かなくても意味が分かります。

論理名表示を見る ↓
WORKFLOW

3ステップで、いつものDBへ

セットアップに時間を取られない。それが道具のあるべき姿。

STEP 01

接続を保存する

ホスト・ユーザー・SSHトンネルを一度登録すれば、次からはダブルクリックで接続。テスト接続で事前確認もできます。

STEP 02

テーブルを眺める

接続した瞬間にテーブル一覧を表示。選ぶだけでカラム・インデックス・テーブル情報がその場で確認できます。

STEP 03

クエリを実行する

行番号付きエディタでSQLを書いて実行。結果は文ごとのタブで整理され、ページングやソートもそのまま操作できます。

HIGHLIGHTS

主要機能

SCHEMA DIFF

本番とステージングの差異を、一発で

接続中の2つの環境(セッション×DB)を選んで「比較」を押すだけ。リリース前の確認や障害調査の初動が変わります。

  • テーブル・カラム・インデックスを比較 — 型・NULL許可・キー・デフォルト・照合順序・コメントまで細かく突き合わせます。
  • 差異部分をハイライト — varchar(20)と(30)のような一部分の違いは、その文字だけを強調表示。全角/半角の混入も見つかります。
  • 「左のみ / 右のみ / 差異あり」で整理 — 差異のみ表示に絞れば、確認すべき箇所だけが残ります。
  • MySQL⇄PostgreSQL間でも比較可能 — 移行時のスキーマ確認にも使えます。

AUTO CAPTURE

クエリと結果を、実行と同時に自動キャプチャ

スイッチをONにして実行するだけで、SQLと結果セットをまとめた画像がファイルとして保存されます。スクショを撮って、切り抜いて、貼り付けて——はもう不要です。

  • エビデンスがそのまま完成 — 実行したSQL・結果・接続先・日時が1枚のPNGに。報告資料や作業記録にそのまま使えます。
  • 複数SQLもまとめて保存 — 文ごとの結果がそれぞれキャプチャされます。
  • 画面の写しではなくデータから描画 — 結果データから直接画像を生成するため、スクロールで隠れた行も欠けません。
  • 保存先は自由 — 設定でフォルダを指定できます。指定しなければOSのダウンロードフォルダに保存されます。
LOGICAL NAMES

カラムの「日本語の意味」がいつも見える

DBコメントに「論理名（説明）」の形式で書いておけば、構造ビューが論理名と補足を別々のカラムに分けて表示。英語のフィールド名と日本語の意味を、行ごとに突き合わせられます。

  • テーブル定義書いらず — customer_id の隣に「顧客ID」。新しくジョインしたメンバーでもすぐDBを読めます。
  • 区切り文字は設定可能 — 「（」以外の区切りにも対応。既存のコメント運用に合わせられます。
  • テーブル名にも論理名 — orders の横に「注文」。一覧から目的のテーブルを探すのが速くなります。
  • 比較・キャプチャとも連動 — スキーマ比較ではコメントの差異も検出されます。

QUERY EDITOR

安全側に倒した、本気のクエリエディタ

書いて、確かめて、実行する。その全部を1画面で完結させました。

  • トランザクションモード — 実行をBEGIN〜COMMITで包み、エラー時は自動ROLLBACK。本番での更新ミスを防ぎます。
  • EXPLAIN / EXPLAIN ANALYZE — ワンクリックで実行計画を確認。結果ヘッダには各カラムの意味がツールチップで出ます。
  • 選択実行 — 選択した部分だけを実行。複数SQLは「;」区切りで文ごとに結果タブに分かれます。
  • 入力補完 — 接続先のテーブル名・カラム名を候補表示。書いている場所を見て「テーブル名だけ」「そのテーブルのカラムだけ」に絞り込みます。
  • エディタの最大化 — 仕切り右端のボタンを押すと、エディタが結果欄まで広がって全画面に。もう一度押すと元の分割に戻ります。
  • SQL整形 — カンマの位置・キーワードの大文字小文字・字下げ・JOINのONの置き方などを設定で選べます (見本を見ながら決められます)。
  • 実行履歴とお気に入り — 実行したSQLは履歴から呼び戻せます。よく使うSQLはフォルダに整理して保存でき、フォルダも項目もドラッグで並べ替えられます。
  • 実行キャンセル・ページング・サーバーサイドソートも標準装備。
ER DIAGRAM

DBから一発リバースで、動かせるER図

「リバース」を押すだけで、外部キー制約と命名規則からリレーションを推測してER図を自動作成。そのままマウスで編集できる、"生きた"図面です。

  • 配置は自由、更新は追従 — テーブルはドラッグで自由配置。再リバースしても配置を維持したまま、カラムの増減だけを反映できます。
  • リレーションも編集できる — カラムからドラッグで線を接続。複合キーの対応付けや線種・色の変更、交差の飛び越え表示にも対応します。
  • 注釈とグルーピング — 枠やテキストで補足を書き込めます。1つの図の中にタブで複数のER図を整理でき、接続をまたいで開けます。
  • 共有は画像でもテキストでも — 日本語の論理名を表示したまま、ライト/ダークに合わせた配色で PNG・SVG に出力。Mermaid / PlantUML でも書き出せるので、GitHubやNotionにそのまま貼れます。
  • 要るテーブルだけ読む — リバースは読み込むテーブルを選ぶところから始まります。数百テーブルのDBでも、必要な範囲だけの図を作れます。

CONNECTIONS

接続が増えても、迷わない

本番・ステージング・ローカル。環境が増えるほど効いてくる整理機能を用意しました。

  • フォルダで整理 — 接続をフォルダにまとめてツリー表示。ドラッグ&ドロップで並べ替えられます。
  • 色分け — 接続ごとに色を設定。タブの色で「いま本番にいる」ことが一目で分かります。
  • SSHトンネル内蔵 — 踏み台経由の接続も鍵認証・パスフレーズ対応でビルトイン。外部ツールは不要です。
  • テスト接続 — 保存前に疎通確認。ダブルクリックですぐ接続できます。
EDITING

定義もデータも、その場で直せる

ALTER文を書かなくても、一覧の行をダブルクリックすればそのまま入力欄。Enterで即反映し、失敗したときはエラーを出してその行を編集状態のまま残します。

  • テーブル定義 — カラムの追加・変更・削除。型と照合順序は接続先から取った一覧から選べ、MySQLならドラッグで並べ替えもできます。インデックスの追加・変更・削除にも対応。
  • テーブルの作成・改名・削除 — 一覧の「+」から雛形を作成。テーブル名も日本語名 (コメント) もその場で変更でき、削除は右クリックから (取り消せないので確認を出します)。
  • データ編集 — データタブでセルをダブルクリックしてUPDATE、行の追加・削除も。値はSQLに埋め込まずプレースホルダで渡します。
  • 事故りにくい作り — 主キーで行を特定できるテーブルだけ編集可。トランザクションで包み、影響が1行でなければ取り消します。取り返しのつかない削除だけは確認を出します。

ALL FEATURES

機能一覧

テーブル定義書のExcel出力

スキーマ一覧から、出力するテーブルを選んで .xlsx を作成。表紙・テーブル一覧・テーブルごとのシート (カラム / インデックス / 外部キー) の構成で、一覧とシートは相互にリンクします。CSVでの出力にも対応。

スキーマ比較

2つの環境を並べてテーブル・カラム・インデックスの差異を検出。差異部分は文字単位でハイライトします。

差分から ALTER 文を生成

スキーマ比較の結果から、左を右に合わせるALTER文を組み立てて表示。消す操作はコメントアウトして出すので、確認してから使えます。

ER図作成

DBからリバースしてER図を自動作成。読み込むテーブルは選べます。配置や線をマウスで編集でき、注釈・タブでの複数管理と、PNG / SVG / Mermaid / PlantUML での書き出しに対応。

結果の自動キャプチャ

実行と同時にクエリ+結果セットをPNGで保存。保存先フォルダは設定で指定でき、エビデンス作成の手間をゼロにします。

日本語の論理名表示

DBコメントの「論理名（説明）」を分割表示。英語カラム名の隣に日本語の意味が常に見えます。

MySQL・MariaDB / PostgreSQL / SQLite / Valkey・Redis

主要なRDBMSに加え、ファイル1つで完結するSQLiteと、Valkey (Redis互換KVS) にも対応。MySQLはMariaDBでも、ValkeyはRedisでもそのまま接続できます。SQLiteはファイルを選ぶだけで開けます。

SSH / SSM / Cloud SQL 経由の接続

踏み台サーバー経由の接続をビルトインで対応（鍵認証・パスフレーズ可）。踏み台へのSSHを禁じている環境向けに、AWS Systems Manager のポート転送と Cloud SQL Auth Proxy にも対応します。TLSは検証レベルと証明書を接続ごとに指定できます。

読み取り専用の接続

接続ごとに読み取り専用を指定。更新系SQL・DDL・行編集をアプリとサーバーの両方で拒否し、タブに R/O バッジを表示します。

テーブル構造ビュー

カラム・インデックス・外部キー・照合順序・コメントまで、定義を1画面で確認。列幅やペインも自由に調整できます。

名前・値からの検索

テーブル名・カラム名・コメントから探す「名前で探す」と、データの中身から探す「値で探す」。見つけた行をダブルクリックでそのテーブルを開きます。

関数・トリガの定義表示

関数・プロシージャ・トリガの定義を名前で絞り込んで確認・コピー。テーブルの CREATE 文もその場で表示できます。

クエリエディタ

行番号付きエディタで複数SQLを実行。結果は文ごとのタブに分かれ、整形・キャンセルにも対応。1つの接続で書きかけのSQLを何枚も持て、設定で次回起動時に戻すこともできます。

クエリ結果のCSVダウンロード

結果タブごとに全件をCSV出力。画面は1000行ずつでも、CSVはそのSQLの全行を書き出します。進捗表示とキャンセル付き。

EXPLAIN / ANALYZE

実行計画をワンクリックで表示。結果ヘッダに各カラムの意味が出るので読み解きも簡単です。

トランザクション実行

実行をBEGIN〜COMMITで包み、エラー時は自動ROLLBACK。更新系の作業も安心です。

接続の整理

フォルダ分け・ドラッグ&ドロップ・色分けに対応。タブの色で接続先を見分けられます。

エクスポート / インポート

複数テーブルをまとめてSQLダンプ出力(スキーマ/データ選択可)。SQLファイルのドロップ実行も。

CSV / TSVの取り込み

ファイルをドロップして、先頭20行を見ながら列の対応を決めて取り込み。区切り文字と文字コードは自動判定、進捗表示と中止に対応します。

日本語のテストデータ生成

カラムの論理名・名前・型から中身を推測して、氏名 (漢字/カナ)・住所・電話番号・会社名などを作って投入。自動採番はDBに任せ、外部キーは参照先にある値から選ぶので整合は崩れません。件数とNULLの割合も指定できます。

クエリログ

アプリが発行した全SQLを専用コンソールで時系列表示。挙動の確認やデバッグに役立ちます。CSV・テキストへの書き出しも可能です。

実行中のSQLの一覧

サーバーで動いている接続とSQLを一覧表示（MySQL / PostgreSQL）。長時間のSQLの中止や、接続の切断も行えます。

テーブル定義の編集

カラム・インデックス・外部キーを一覧上でその場編集。追加・変更・削除、型や照合順序の選択、MySQLはドラッグでの並べ替えにも対応。

テーブル・データベースの作成

カラム・型・主キー・自動採番・文字コードまで決めてからテーブルを作成。データベースやスキーマの作成・削除にも対応し、実行するSQLを確認してから流します。

データ編集

データタブでセルを直接編集してUPDATE、行の追加・削除も。トランザクションで包み、1行だけ変わったことを確認して確定します。

SQLの入力補完

テーブル名・カラム名を書いている場所に合わせて候補表示。カラムは日本語名と型も並べて出します。待ち時間は設定で調整可能。

対応バージョンや、データベースごとにできること・できないことは 機能詳細 にまとめています。

FAQ

よくある質問

本番とステージングのスキーマのずれを確認できますか?
できます。それがQuelioの看板機能です。接続中の2つの環境を選んで比較すると、テーブル・カラム・インデックスの差異が「左のみ / 右のみ / 差異あり」で一覧表示され、型の長さ違いのような細かな差異は該当文字だけがハイライトされます。
クエリ結果のキャプチャはどこに保存されますか?
実行したSQL・結果・接続先・日時を含むPNG画像として保存されます。保存先は設定 > 一般の「保存先フォルダ」で指定でき、指定がなければOSのダウンロードフォルダに保存されます (CSV出力やエクスポートも同じフォルダを使います)。キャプチャスイッチをONにして実行するだけで、文ごとに1枚ずつ自動保存されます。
カラムの論理名(日本語名)を表示するには?
DBのカラムコメントに「論理名（説明）」の形式で書いておくと、構造ビューで論理名と補足が別カラムに分かれて表示されます。区切り文字は設定で変更できるため、既存のコメント運用のままで使えます。
対応しているデータベースは?
MySQL・PostgreSQL・SQLiteと、Valkey (Redis互換のKVS) に対応しています。MySQLの接続はMariaDB (10.x / 11.x)、Valkeyの接続はRedis (6.0以降) でもそのまま使えます。SQLiteはサーバー不要で、データベースファイルを選ぶだけで開けます。1つのアプリ内で複数の接続をタブで同時に開けます。ValkeyはAWS ElastiCache (Serverless含む) へのTLS接続にも対応しています。
対応OSは?
macOS (Apple Silicon) と Windows に対応しています。Tauri製のネイティブアプリなので、ブラウザは不要です。
macOSでキーチェーンへのアクセス許可を求められるのはなぜ?
接続パスワードを安全に保存するためです。Quelioは保存するパスワードをAES-256-GCMで暗号化し、その暗号鍵(マスターキー)だけをmacOSのキーチェーンに保管します(Windowsでは資格情報マネージャー)。初回起動時やアップデート後にダイアログが出た場合は「常に許可」を選ぶと、次回以降は表示されません。パスワードを平文のままファイルに保存することはありません。
英語UIはありますか?
Quelioは日本語専用のアプリです。メニューや設定を含むすべてのUIが日本語で、論理名表示など日本の開発現場のコメント運用に合わせた機能を優先して作っています。英語UIは現在提供していません。
接続情報はどこに保存されますか?
接続プロファイルはお使いのPCのローカルにのみ保存され、外部サーバーへ送信されることはありません。パスワードとSSHパスフレーズはAES-256-GCMで暗号化され、暗号鍵はOSのキーチェーンに保管されます。
無料で使えますか?
無料です。MIT Licenseのオープンソースソフトウェアとして公開しており、商用環境でもお使いいただけます。現在はベータ版のため、重要なデータベースで使う際は事前のバックアップをおすすめします。
本番DBで誤って更新してしまわないか不安です
トランザクションモードを有効にすると、実行がBEGIN〜COMMITで包まれ、途中でエラーになった場合は自動でROLLBACKされます。また接続ごとの色分けで、本番タブを視覚的に区別できます。
テーブル定義やデータを画面から変更できますか?
できます。構造ビューの行をダブルクリックすると、カラムやインデックスをその場で編集でき、テーブルの作成・改名・日本語名(コメント)の変更も画面から行えます。データタブではセルを直接編集してUPDATEでき、行の追加・削除にも対応しています。データ編集は主キーで行を特定できるテーブルのみ有効で、実行はトランザクションで包み、影響が1行でなければ取り消します。SQLiteは仕様上、カラムの追加・削除・改名のみ対応です。
SQLを書くときに補完は効きますか?
効きます。接続先から取得したテーブル名・カラム名を候補に出し、FROMやJOINの直後はテーブル名だけ、テーブルが決まっている場所ではそのテーブルのカラムだけに絞り込みます。カラムの候補にはコメントから取り出した日本語名と型も並びます。自動表示までの待ち時間は設定で変更でき、0にすれば⌥Spaceを押したときだけ表示します。
SSH踏み台経由でしか接続できないDBにも使えますか?
使えます。SSHトンネル機能を内蔵しており、鍵認証・パスフレーズ付き鍵にも対応しています。別途トンネルを張るツールは不要です。
